Pustaka Kita adalah aplikasi web sistem perpustakaan mini untuk mengelola koleksi buku

Pengguna masuk lewat halaman login, lalu username-nya diteruskan ke tiga halaman lain

Dashboard: menampilkan sapaan, statistik perpustakaan, dan aktivitas terbaru.
Pengelolaan: menampilkan daftar buku (judul, penulis, kategori, stok, status) dalam bentuk tabel.
Profile: menampilkan informasi anggota dan minat bacaan.

Semua data disimpan di controller dan dikirim ke view, dan tampilannya responsif memakai CSS buatan sendiri.
